# agent-monitor

A Claude Code mod: a side pane that shows live which tasks the agent runs, with the model, reasoning effort and estimated cost of each. It also asks before a request that would rewrite more than $2 of cold prompt cache.

## Install

At the prompt of a terminal session:

```
/plugin install agent-monitor --marketplace soudmaijer/agent-monitor
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install agent-monitor --marketplace soudmaijer/agent-monitor
```
